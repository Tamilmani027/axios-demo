# Axios User Manager

A small React and Vite app for managing user records through a REST API. You can view, add, edit, and delete users.

## Run locally

```bash
npm install
npm run dev
```

## Commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run lint checks

Built with React, Vite, and Axios.
